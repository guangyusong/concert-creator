# Concert Creator (live site)

The built web player, published from the Concert Creator source by `scripts/deploy-pages.sh`.
Open it at https://guangyusong.github.io/concert-creator/

Free and non-commercial. The player's code is MIT-licensed, but this site also carries:

- the song library: performances from MAESTRO v3 (CC BY-NC-SA 4.0) with learned fingering;
- the learned hand-motion model (`models/motion/`), trained on the FürElise dataset (CC BY-NC 4.0);
- the grand piano model: "grand piano" by local.yany, CC BY 4.0.

So it is not for commercial use. Full credits: [credits.html](credits.html).
